# Examples

These two examples are from (https://ethrat.ch/en/ord-measure-2/)[ETHZ ORD Measure 2]. They are from project that promote interoperability between [openBIS](https://openbis.ch/) with [SciLog](https://www.psi.ch/en/awi/scilog) and [SciCat](https://www.scicatproject.org/).

The examples illustrate what the profile looks like. All data and metadata in the examples is fakes. The metadata provides examples of how entities are linked and a variety of data types, including rich text with images and vocabularies.
